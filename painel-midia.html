Passo a Passo para Ligar Tudo de Graça Hoje

O código das APIs já está no repositório em functions/api/. Falta só plugar as chaves no Cloudflare Pages:

  1. Pasta oficial do Google Drive já definida: ID 1ljHShoUD_gXBM3D-FhrZCdSHpt0tQI6v já configurado no backend (functions/api/) como padrão.
  2. Gerar credencial grátis OAuth do Google Drive: no Google Cloud Console (sem cartão), ative a Google Drive API, crie credencial OAuth Web (usando OAuth Playground com escopo drive.file) e pegue GOOGLE_CLIENT_ID, GOOGLE_CLIENT_SECRET e GOOGLE_REFRESH_TOKEN.
  3. Pegar chave gratuita do Gemini (Google AI Studio): gere uma API Key para analisar os roteiros no endpoint /api/gerar-roteiro.
  4. Colar no Cloudflare Pages → Settings → Environment variables: adicione GOOGLE_DRIVE_FOLDER_ID (1ljHShoUD_gXBM3D-FhrZCdSHpt0tQI6v), GOOGLE_CLIENT_ID, GOOGLE_CLIENT_SECRET, GOOGLE_REFRESH_TOKEN, GEMINI_API_KEY, EQUIPE_EMAILS e TEAM_PIN.
